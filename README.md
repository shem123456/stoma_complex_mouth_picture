# 气孔开闭状态检测工具

该工具用于从显微镜图像中提取气孔的开闭状态，可识别气孔位置、长轴、短轴等信息。

## 环境配置

### 依赖安装

```bash
pip install tensorflow-gpu==1.13.1
pip install keras==2.1.5
pip install opencv-python==4.2.0.34
pip install pandas
```

> **注意**：如果用户没有 GPU，可以安装 `tensorflow==1.13.1` 版本，具体根据用户环境选择。

## 使用方法

### 1. 准备数据

将待处理的显微镜图像放入 `img` 文件夹中。

### 2. 运行程序

```bash
python photo_demo_open_close.py
```

### 3. 查看结果

- 处理后的图像保存在 `img_out` 文件夹中
- 检测结果（包括气孔位置、长轴、短轴等信息）保存在 `result.csv` 文件中

## 模型说明

运行程序前需要确保已训练好的模型存在。如果模型文件缺失，请检查项目目录或联系开发者获取预训练模型。

## 输出格式

`result.csv` 文件包含以下列：
- 图像文件名
- 气孔位置坐标
- 气孔长轴长度
- 气孔短轴长度
- 气孔开闭状态
